SyncDrive T3 · External Interface

對外介面入口

台智駕 SyncDrive T3 車輛行車管理系統，提供給協力廠商的唯讀介面。

介接文件 →

介接說明書、即時 ETA 與班表兩份規格。第一次串接請從這裡開始。

Swagger →

四支介面的線上規格，可直接 Try it out。右上角 Authorize 填入金鑰。

四支介面

GET /syncdrive-api/operation-shift/timetable/trips 全部班次與逐站計畫時刻
GET /syncdrive-api/operation-shift/timetable/station-etas 站點計畫事件流（依站索引）
GET /syncdrive-api/vehicles/eta/by-station 各站接下來會到的車　建議輪詢 60 秒
GET /syncdrive-api/vehicles/eta/by-vehicle 各車接下來會到的站　建議輪詢 60 秒
這個埠只有上面四支。同一台主機上的其他系統在這個埠一律回 404——不是權限不足，是不存在。

認證

本入口頁與文件需要瀏覽帳號；API 本身用的是另一組金鑰，兩者不共用。 

curl -H "X-API-Key: <你的金鑰>" \
  "http://<本站位址>/syncdrive-api/vehicles/eta/by-station"
金鑰或帳號有問題請聯絡我方窗口。介接過程若發現回應與文件不符，請以實際回應為準並通知我方。
