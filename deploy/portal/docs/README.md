# SyncDrive T3 對外文件

本站收錄**對外介面與通訊協議**。左側十份即為全部內容。

先確認你屬於哪一種取用方，兩份說明書的內容完全不同：

| 你要做的事 | 從這裡開始 |
|-----------|-----------|
| **讀取班表與到站預測**（站端看板、SCADA、App） | [介接說明書](協力廠商介接說明書.md)——認證方式、四支唯讀 API、最容易誤解的三件事 |
| **把車接上來**（自駕車廠商） | [車端介接說明書](車端介接說明書.md)——三條通道、從班表發布到車輛移動的七個步驟、七份 JSON Schema |
