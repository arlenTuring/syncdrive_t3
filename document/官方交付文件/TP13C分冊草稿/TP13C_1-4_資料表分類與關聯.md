# 1.4 資料表分類與關聯（車輛行車管理，含車輛監控系統）

> 貼入位置：TP13C §1.4「資料表分類與關聯」既有表格之後，接續新增本系統之分類表。
> 該節目前僅列出車輛巡航管理系統（自駕車端）之資料表。

---

本系統資料表依用途分為十大類，共 37 張資料表，各分類及對應資料表如下表所示。

The data tables of this system are classified into ten categories comprising 37 data tables according to their purpose. The categories and their corresponding data tables are shown in the following table.

| 分類 Category | 說明 Description | 對應資料表 Data Tables |
|---|---|---|
| 主檔 Master Data | 車輛基本資料與外觀定義、路線、站點動作及設施格位之基本資料與設定<br>Master data and configuration of vehicles and their appearance definitions, routes, station actions and facility slots | vehicles、vehicle_definitions、operation_routes、operation_route_stations、operation_route_station_actions、facility_slots |
| 營運排程 Operation Scheduling | 時間模板、整備任務設定、營運班表（含班次、整備時段與調度移動）及班表調整之簽核請求<br>Time templates, maintenance task configuration, operational schedules (including trips, maintenance slots and dispatch movements), and schedule adjustment approval requests | time_templates、maintenance_tasks、operation_shifts、schedule_adjust_requests |
| 服務與訂單 Service and Order | 服務訂單、站點動作狀態及訂單事件紀錄<br>Service orders, station action states and order event records | operation_orders、order_action_states、order_events |
| 場域圖資 Field Map Data | 場域地圖主檔與逐版圖資內容（節點、有向邊與行駛時間、站點、設施、區域）；草稿與已發布版本均集中保存，對所有帳號一致<br>Field map master data and versioned map content (nodes, directed edges with travel times, stations, facilities and areas); both drafts and published versions are stored centrally and are consistent for all accounts | maps、map_versions |
| 場域與設備狀態 Field and Equipment Status | 路側設備健康狀態、設施格位即時狀態及路口閉鎖生命週期紀錄<br>Health status of roadside equipment, real-time status of facility slots, and junction interlock lifecycle records | field_equipment_status、slot_statuses、junction_interlock_logs |
| 車輛遙測與控制指令 Vehicle Telemetry and Control Command | 車端回傳之原始遙測資料、控制指令下達與回覆紀錄及速限設定<br>Raw telemetry data reported by vehicles, control command issuance and response records, and speed limit configuration | telemetry_logs、command_logs、speed_limit_configs |
| 介面資源 Interface Resources | 營運全景圖台版面與模組頁面對應、圖台元件之資料來源定義，及車上廣播媒體內容、分組與播放排程<br>Operation panorama dashboard layouts and their module page mappings, data source definitions bound by dashboard widgets, and on-board broadcast media content, groups and playback schedules | dashboard_planes、module_dashboard_pages、data_sources、media_library_items、media_schedules |
| 帳號與權限 Account and Permission | 操作人員帳號、角色、功能權限項目及其綁定關係<br>Operator accounts, roles, function permission items and their binding relationships | accounts、roles、permissions、role_permissions、account_roles |
| 稽核日誌 Audit Logs | 營運操作、登入登出、權限異動及資安事件之稽核紀錄<br>Audit records of operational activities, login/logout events, permission changes and information security events | operator_action_logs、login_logs、permission_change_logs、security_event_logs |
| 系統基礎 System Base | 系統參數設定及全域通知訊息<br>System parameter settings and global notification messages | system_settings、notifications |

### 資料表用途說明

| 分類 Category | 資料表名稱 Data Table | 用途說明 Description |
|---|---|---|
| 主檔 Master Data | `vehicles` | 車輛主檔，記錄車輛代號、顯示名稱與啟用狀態。<br>Vehicle master data: vehicle code, display name and active status. |
|  | `vehicle_definitions` | 載具外觀定義，保存車體、車門、座位與狀態指示等呈現元件。<br>Vehicle appearance definitions: rendering elements for body, doors, seats and status indicators. |
|  | `operation_routes` | 營運路線主檔，記錄路線名稱、上下行別與方向代號。<br>Operational route master data: route name, line direction and direction code. |
|  | `operation_route_stations` | 路線之停靠站序，定義各路線依序經過的站點。<br>Station sequence of each route, defining the stations passed in order. |
|  | `operation_route_station_actions` | 站點動作定義，記錄各站應執行之動作類型與觸發距離。<br>Station action definitions: action type and trigger offset at each station. |
|  | `facility_slots` | 場域設施格位靜態定義，如充電樁、洗車與駐車格位。<br>Static definitions of field facility slots, such as charging, washing and parking slots. |
| 營運排程 Operation Scheduling | `time_templates` | 時間模板，定義各時段之區間、班距與運能需求。<br>Time templates defining interval ranges, headways and capacity requirements. |
|  | `maintenance_tasks` | 整備任務設定，涵蓋充電、行檢、保養、待命與洗車。<br>Maintenance task configuration covering charging, inspection, servicing, standby and washing. |
|  | `operation_shifts` | 營運班表，包含載客班次、整備時段與調度移動。<br>Operational schedules including passenger trips, maintenance slots and dispatch movements. |
|  | `schedule_adjust_requests` | 班表調整之簽核請求，記錄申請內容、狀態與核准歷程。<br>Schedule adjustment approval requests: content, status and review history. |
| 服務與訂單 Service and Order | `operation_orders` | 服務訂單，記錄班次代號、路線、車輛、優先序、延誤與預估到站。<br>Service orders: trip code, route, vehicle, priority, delay and estimated arrival. |
|  | `order_action_states` | 訂單之站點動作執行狀態，記錄實際起訖時間。<br>Execution status of station actions for each order, with actual start and end times. |
|  | `order_events` | 訂單事件紀錄，包含請求狀態、完成狀態與處理時間。<br>Order event records including request status, completion status and resolution time. |
| 場域圖資 Field Map Data | `maps` | 場域地圖主檔，記錄地圖識別碼、啟用狀態與最新版本號。<br>Field map master data: map identifier, active status and current version number. |
|  | `map_versions` | 逐版圖資內容，保存節點、有向邊與行駛時間、站點、設施與區域；草稿與已發布版本均存於此。<br>Versioned map content: nodes, directed edges with travel times, stations, facilities and areas; both drafts and published versions are stored here. |
| 場域與設備狀態 Field and Equipment Status | `field_equipment_status` | 路側設備登錄與最新健康狀態，供圖台顯示設備告警。<br>Roadside equipment registry and latest health status for dashboard alarm display. |
|  | `slot_statuses` | 設施格位即時狀態，每一格位保存一筆最新狀態。<br>Real-time status of facility slots; one latest record per slot. |
|  | `junction_interlock_logs` | 路口閉鎖生命週期紀錄，涵蓋請求、授予、持有與釋放。<br>Junction interlock lifecycle records covering request, grant, hold and release. |
| 車輛遙測與控制指令 Vehicle Telemetry and Control Command | `telemetry_logs` | 車端回傳之原始遙測資料，以時序資料表保存完整內容。<br>Raw telemetry reported by vehicles, stored complete in a time-series table. |
|  | `command_logs` | 控制指令下達與回覆確認紀錄。<br>Records of control command issuance and acknowledgement. |
|  | `speed_limit_configs` | 速限設定本身，供車端查詢目前適用速限。<br>Speed limit configuration itself, queried by vehicles for the applicable limit. |
| 介面資源 Interface Resources | `dashboard_planes` | 營運全景圖台版面，保存畫布元件樹、適配模式與版本。<br>Operation panorama dashboard layouts: canvas element tree, viewport mode and version. |
|  | `module_dashboard_pages` | 各功能模組與圖台版面之對應關係。<br>Mapping between functional modules and dashboard layouts. |
|  | `data_sources` | 圖台元件之資料來源定義，支援內部查詢、REST 與 MQTT。<br>Data source definitions bound by dashboard widgets, supporting internal query, REST and MQTT. |
|  | `media_library_items` | 車上廣播之媒體內容與播放群組。<br>On-board broadcast media content and playback groups. |
|  | `media_schedules` | 媒體播放排程，定義觸發條件、生效範圍與優先序。<br>Media playback schedules defining trigger conditions, applicable scope and priority. |
| 帳號與權限 Account and Permission | `accounts` | 操作人員帳號主檔，密碼僅保存雜湊值。<br>Operator account master data; passwords are stored as hashes only. |
|  | `roles` | 角色主檔，定義系統內之操作角色。<br>Role master data defining operational roles within the system. |
|  | `permissions` | 功能權限項目字典，每筆對應一個可授權之功能點。<br>Dictionary of function permission items; each entry corresponds to one grantable function. |
|  | `role_permissions` | 角色與功能權限之對應關係。<br>Mapping between roles and function permissions. |
|  | `account_roles` | 帳號與角色之綁定關係，一個帳號可綁定多個角色。<br>Binding between accounts and roles; one account may hold multiple roles. |
| 稽核日誌 Audit Logs | `operator_action_logs` | 操作人員行為稽核紀錄，含操作人員、來源位址、操作內容與執行結果。<br>Operator activity audit records including operator, source address, action content and result. |
|  | `login_logs` | 帳號登入、登出與登入失敗紀錄。<br>Records of account login, logout and failed login events. |
|  | `permission_change_logs` | 帳號、角色與功能權限之異動歷程，保留異動前後內容。<br>Change history of accounts, roles and permissions, retaining values before and after each change. |
|  | `security_event_logs` | 資安與車輛事件紀錄，含事件代碼、分類與確認狀態。<br>Information security and vehicle event records including event code, category and acknowledgement status. |
| 系統基礎 System Base | `system_settings` | 系統層級可調參數，以鍵值形式保存並記錄值型別。<br>System-level adjustable parameters stored as key/value pairs with value types. |
|  | `notifications` | 系統對操作人員發出之通知訊息，可指定接收對象或全域發送。<br>Notification messages issued to operators, either targeted or global. |

註1：各資料表之欄位定義詳第02584K章附錄4，本計畫書不重複列載。

註2：場域圖資之草稿與已發布版本均保存於 maps 與 map_versions；圖資為全系統共用資產，任一帳號所見內容一致。

註3：系統另有展示用示範資料表，非營運資料，未列入本表。

註4：資料表設計後續依實際營運狀況調整。
