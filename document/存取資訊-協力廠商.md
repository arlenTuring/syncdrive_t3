### 五、常見問題

| 狀況 | 原因 |
|------|------|
| API 回 `401` | 沒帶 `X-API-Key` 或值不對 |
| 班表 API 回 `404` | 目前庫內沒有已發布班表。這是正常回應，不是故障 |
| 即時 ETA 各站都是空的 | 該時段車輛都在整備區，沒有正線車。換時段再看 |
| `data_quality` 是 `DEGRADED` | 部分車輛資料逾時，其餘資料仍可用 |
| MQTT 連不上 | 帳密錯誤，或未帶帳密 |

**失聯是以「資料變舊」呈現，不是資料消失。**車輛停止回報時仍會出現在回應中，
只是 `data_age_seconds` 持續累加、`arrival_state` 轉為 `UNKNOWN`。請檢查這兩個
欄位，不要只判斷車輛是否存在。

有任何回應與文件不符之處，請以實際回應為準並通知我方。
