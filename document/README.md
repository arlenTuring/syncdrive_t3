# SyncDrive T3 文件中心

歡迎使用 SyncDrive T3 技術文件 Wiki。

請從左側邊欄選擇文件類別瀏覽。

---

## 怎麼打開這份 Wiki

在專案根目錄執行：

```bash
npm run docs
```

瀏覽器開啟：**[http://localhost:4000](http://localhost:4000)**

---

## 文件索引

### 排班引擎

排班規則只保留一份白皮書 HTML（檔名沿用 `排班引擎算法全覽-審核.html`，程式與測試引用這個路徑）；這一組因為互相以相對路徑連結、且
`排班引擎最近問題.html` 的路徑寫死在後端（`backend/src/dev-log/dev-log.controller.ts`），
固定放在 `document/` 根目錄，不搬進分類資料夾。

| 文件 | 說明 |
|------|------|
| [排班引擎白皮書](排班引擎算法全覽-審核.html) | **排班規則唯一正式文件**：已確認規則、待確認事項、現況差異；舊實作說明在頁內歷史附錄（`document/排班引擎算法全覽-審核.html`）。本機開發另可開 http://localhost:3100/schedule-whitepaper/ |
| [最近一次生成的問題](排班引擎最近問題.html) | **逐則**錯誤／警告（每次重新生成覆寫） |
| [點位拓撲規格](點位拓撲規格.md) | 地圖拓撲、站間 leg、路線加總 |
| [班表 Timetable API](班表Timetable-API.md) | **可打的 HTTP**：班次逐站時刻、站點計畫 ETA |
| [班表 ETA 取用範例](班表ETA取用範例.html) | **HTML 欄位框**：依站分組，點「欄位」看每個 API 欄位 |
| [班次可讀檢視](班表班次檢視.html) | **HTML 欄位框**：以車列分頁籤，正線／整備等班次可展開 |

- http://localhost:4000/排班引擎算法全覽-審核.html
