# 1.4 資料表分類與關聯（車輛行車管理，含車輛監控系統）

> 貼入位置：TP13C §1.4「資料表分類與關聯」既有表格之後，接續新增本系統之分類表。
> 該節目前僅列出車輛巡航管理系統（自駕車端）之資料表。

---

本系統資料表依用途分為九大類，共 30 張資料表，各分類及對應資料表如下表所示。

The data tables of this system are classified into nine categories comprising 30 data tables according to their purpose. The categories and their corresponding data tables are shown in the following table.

| 分類 Category | 說明 Description | 對應資料表 Data Tables |
|---|---|---|
| 主檔 Master Data | 車輛、路線、站點動作及設施格位之基本資料與設定<br>Master data and configuration of vehicles, routes, station actions and facility slots | vehicles、operation_routes、operation_route_stations、operation_route_station_actions、facility_slots |
| 營運排程 Operation Scheduling | 時間模板、整備任務設定及營運班表（含班次、整備時段與調度移動）<br>Time templates, maintenance task configuration and operational schedules (including trips, maintenance slots and dispatch movements) | time_templates、maintenance_tasks、operation_shifts |
| 服務與訂單 Service and Order | 服務訂單、站點動作狀態及訂單事件紀錄<br>Service orders, station action states and order event records | operation_orders、order_action_states、order_events |
| 場域與設備狀態 Field and Equipment Status | 路側設備健康狀態、設施格位即時狀態及路口閉鎖生命週期紀錄<br>Health status of roadside equipment, real-time status of facility slots, and junction interlock lifecycle records | field_equipment_status、slot_statuses、junction_interlock_logs |
| 車輛遙測與控制指令 Vehicle Telemetry and Control Command | 車端回傳之原始遙測資料、控制指令下達與回覆紀錄及速限設定<br>Raw telemetry data reported by vehicles, control command issuance and response records, and speed limit configuration | telemetry_logs、command_logs、speed_limit_configs |
| 介面資源 Interface Resources | 營運全景圖台版面（畫布元件樹與適配模式）及多媒體內容與播放排程<br>Operation panorama dashboard layouts (canvas element tree and viewport mode), and multimedia content with playback scheduling | dashboard_planes、media_library_items |
| 帳號與權限 Account and Permission | 操作人員帳號、角色、功能權限項目及其綁定關係<br>Operator accounts, roles, function permission items and their binding relationships | accounts、roles、permissions、role_permissions、account_roles |
| 稽核日誌 Audit Logs | 營運操作、登入登出、權限異動及資安事件之稽核紀錄<br>Audit records of operational activities, login/logout events, permission changes and information security events | operator_action_logs、login_logs、permission_change_logs、security_event_logs |
| 系統基礎 System Base | 系統參數設定及全域通知訊息<br>System parameter settings and global notification messages | system_settings、notifications |

註1：各資料表之欄位定義詳第02584K章附錄4，本計畫書不重複列載。

註2：場域圖資（路網拓樸、站點與設施座標）以發布版本之圖資檔案保存，不另立資料表。

註3：系統另有展示用示範資料表，非營運資料，未列入本表。

註4：資料表設計後續依實際營運狀況調整。
