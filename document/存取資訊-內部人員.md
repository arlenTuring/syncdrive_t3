## 三、目前的安全邊界（要知道的三件事）

**1. 圖台沒有登入系統。**畫面右上角的「登入帳號」是示範帳號切換器，用來預覽主管／
一般員工的不同畫面，不驗證身分也不限制操作。真正的權限管理屬 milestone 5，尚未
開發。所以**任何拿到 `syncdrive` 或 `vendor` 帳密的人，都能操作圖台、讀寫班表與
地圖**——這道 Basic Auth 是目前唯一的保護。

**2. 三個埠都對全世界開放，靠帳密與金鑰擋。**

| 埠 | 對象 | 保護 |
|----|------|------|
| 80 | 我方與廠商看圖台 | Basic Auth（兩組帳號） |
| 3100 | 廠商介接 | Basic Auth ＋ API 金鑰 |
| 1883 | 車端 MQTT | 帳密 ＋ ACL |

先前用 IP 白名單擋 80 埠，但我們是浮動 IP——2026-08-26 IP 一換就整個連不上，
所以改成帳密。

**3. 資料庫與 Redis 不對外。**只綁 `127.0.0.1`，要進去得走 SSH 通道。

## 四、常見狀況

| 狀況 | 處理 |
|------|------|
| 圖台一直轉圈、打不開 | 先確認服務有沒有掛（見下方指令）。若是「連不上」而非錯誤頁，多半是伺服器沒起來 |
| 跳出帳密框輸入後還是被拒 | 確認用的是 `syncdrive` 而不是 `vendor` 或 `partner` |
| 圖台開得起來但沒有資料 | 資料庫的起始資料沒匯入，需在伺服器上跑 `./deploy/seed-restore.sh` |
| 班表 API 回 404 | 庫內沒有已發布班表，這是正常回應 |

連進伺服器與檢查狀態：

```bash
gcloud compute ssh syncdrive-t3 --zone=asia-east1-a
sudo docker ps                          # 哪個容器沒起來
cd /opt/syncdrive_t3 && ./deploy/healthcheck.sh   # 33 項驗收
```
