# 1.3.4 車輛行車管理（含車輛監控系統）

> 貼入位置：TP13C §1.3「軟體程式功能說明」底下、第三層標題
> 「車輛行車管理（含車輛監控系統）」之下（目前為空白）。標題已存在，只貼標題下方內文。

---

車輛行車管理（含車輛監控系統）為全場域營運之核心監控與管理平台。系統彙整車輛、場域設施及事件資訊，於營運全景圖台集中呈現；依營運需求建立時間模板、路線群組及整備任務，產生營運班表並完成可行性檢核與部署；營運期間執行派遣調度、降級運轉及車門月台控制，並將營運策略結果交付車輛巡航管理系統（中心端）執行。系統另提供載具、場域、服務與媒體等營運資源管理，以及帳號權限、日誌稽核與系統參數等後勤管理功能。

The Vehicle Traffic Management System (incl. Vehicle Monitoring System) is the core operational monitoring and management platform for the entire field. It aggregates vehicle, field facility and event information and presents them centrally on the operation panorama dashboard. Based on operational requirements, it establishes time templates, route groups and maintenance tasks, generates operational schedules, and completes feasibility verification and deployment. During operation it performs dispatch management, degraded operation management and vehicle/platform door control, and delivers the resulting operating strategies to the Vehicle Cruise Management System (Center Side) for execution. The system also provides management of operational resources such as vehicles, field data, services and media, together with logistics functions including account permissions, log auditing and system parameters.

## 軟體分層設計與功能說明

車輛行車管理（含車輛監控系統）共分為四層，各層亦劃分不同功能模組，功能模組與其子功能職責細部說明請參閱第02584K章 車輛行車管理系統2.2.3說明。

The Vehicle Traffic Management System (incl. Vehicle Monitoring System) is divided into four layers, each further divided into functional modules. For detailed descriptions of the functional modules and the responsibilities of their sub-functions, please refer to Section 02584K, Vehicle Traffic Management System, Clause 2.2.3.

## 功能模組與子功能模組清單

- **營運核心層 Operation Core Layer**
  - 數據監控模組 Data Monitoring Module
    - 營運全景圖台 Operation Panorama Board
    - 載具監控數據 Vehicle Monitoring Data
    - 即時班表資訊 Realtime Schedule Infomation
    - 即時營運數據 Realtime Operation Data
  - 營運管理模組 Operation Management Module
    - 班表部署管理 Schedule Deploy Mgmt
    - 降級運轉管理 Degraded Operation Mgmt
    - 派遣調度管理 Vehicle Dispatch & Recall
    - 車門月台控制 Door & Platform Control
  - 班表管理模組 Schedule Management Module
    - 班表規劃部署 Schedule Planning
    - 班表清單管理 Schedule List
    - 班次運行紀錄 Trip Operation History
    - 整備任務管理 Maintenance Task Mgmt
  - 事件管理模組 Event Management Module
    - 事件即時清單 Event Realtime List
    - 歷史事件檢視 Event History Query
    - 事件報表輸出 Event Report Export
    - 影像監控管理 Video Monitoring
- **資源配置層 Resource Config Layer**
  - 載具管理模組 Vehicle Management Module
    - 即時資訊清單 Vehicle Current Info List
    - 運行日誌查詢 Operation Log Query
    - 歷史軌跡回放 Route Replay
    - 載具註冊管理 Vehicle Register
  - 場域管理模組 Field Management Module
    - 虛擬圍籬管理 Geo-fence Mgmt
    - 圖資資料管理 Map Data Mgmt
    - 站點資訊管理 Station Info Mgmt
    - 設施資訊管理 Facility Info Mgmt
  - 服務管理模組 Service Management Module
    - 路線任務規劃 Route Task Planning
    - 排程訂單管理 Schedule Order Mgmt
    - 建立訂單作業 Order Creation
    - 訂單紀錄清單 Order Records
  - 媒體管理模組 Media Management Module
    - 媒體內容清單 Media Content List
    - 媒體分組管理 Media Group Mgmt
    - 媒體檔案設定 Media File Config
    - 媒體排程設定 Media Scheduling
- **資通訊安全層 Communication Security Layer**
  - 資訊通訊模組 Access Management Module
    - 協定接入管理 Protocol Access Management
    - 外部系統整合 External System Integration
    - 通訊加密服務 Communication Encryption
    - 資料存取閘道 Data Access Gateway
- **後勤管理層 Logistics Mangament Layer**
  - 權限管理模組 Access Management Module
    - 帳號管理中心 Account Mgmt Center
    - 角色管理設定 Role Management Setting
    - 功能權限設定 Function Access Control
    - 帳號角色綁定 Account Binding
  - 日誌管理模組 Field Management Module
    - 系統操作紀錄 System Operation Log
    - 權限異動查詢 Permission Change Log
    - 營運操作紀錄 Operation Control Log
    - 登入登出紀錄 Login History Log
  - 系統基礎模組 System Foundation Module
    - 全域通知提醒 Global Notification
    - 登入資訊顯示 Login Info Display
    - 系統參數設定 System Config Setting
    - 系統監測狀態 System Health Status

## 功能模組輸入與輸出、觸發條件

### 營運核心層 Operation Core Layer

**數據監控模組 Data Monitoring Module**

| 項目 | 內容 |
|---|---|
| 子功能 | - 營運全景圖台 Operation Panorama Board<br>- 載具監控數據 Vehicle Monitoring Data<br>- 即時班表資訊 Realtime Schedule Infomation<br>- 即時營運數據 Realtime Operation Data |
| 輸入（Input） | 場域圖資與路網拓樸（站點、路段、設施座標）<br>車輛即時狀態（位置、方向、速度、任務狀態）<br>IOT SCADA 提供之場域設施狀態與告警<br>已部署之營運班表與班次資訊 |
| 輸出（Output） | 營運全景圖台之路網、設施與車輛圖示顯示<br>載具監控數據與設施狀態顯示<br>即時班距、各站點抵達時間及月台預估人次<br>即時營運數據統計與圖表 |
| 觸發條件（Trigger） | 操作人員開啟圖台或監控頁面<br>車輛狀態或設施狀態更新<br>班表部署或班次狀態變更 |

| 輸入（Input） | 已完成可行性檢核之營運班表<br>車輛可用狀態與整備狀態<br>操作人員之派遣、降級及門控操作指令<br>月台門與車門狀態 |

| 觸發條件（Trigger） | 操作人員執行班表部署或取消部署<br>營運異常需切換降級模式<br>需人工介入派遣或調整車輛任務<br>操作人員執行門控操作 |
