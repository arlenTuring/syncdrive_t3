# 車輛動態協議 (Telemetry Protocol) 規格書

> 目前版：2026-09-18。站點以 [T3 地圖清單](T3地圖站點與路線清單.md) 為準；訂單新規格見 [錯誤與對帳](訂單API錯誤與對帳.md)。

## 一、 協議定位與通訊基礎
* **通訊協定**: MQTT
* **連線認證**: **必要**。車端一律連 **8883**，TLS 雙向驗證；客戶端憑證的 CN 必須等於自身 `vehicle_code`。詳見 [MQTT 通訊架構與 Topic 命名規範](MQTT%20通訊架構與%20Topic%20命名規範.md) §三。
* **Topic**: `v1/vtms/{vehicle_code}/telemetry/update`
* **發送頻率**: 1Hz
* **核心用途**: 本協議定位為 SyncDrive-T3 系統的**「高頻數位分身資料流」**。為確保系統網路與資料庫效能，本協議**嚴格剔除所有派車業務邏輯與硬體健康狀態**，僅保留純粹的空間與運動學數值，專供時序資料庫 (TSDB) 儲存及前端 GIS 監控圖台進行高頻平滑渲染使用。

以下範例情境：車輛 **PMS05** 正在以 2.92 m/s（約 10.5 km/h）行駛中，並回傳當下絕對座標、車輛姿態與底盤線控反饋。

```json
  "timestamp": 1716536357000,
  "global_pose": {
    "latitude": 25.077612,
    "longitude": 121.232545,
    "altitude": 6.15
  },
  "local_pose": {
    "position": {
      "x": 176330.86,
      "y": 1969.98,
      "z": 6.15
    },
    "orientation": {
      "w": 0.6865,
      "x": 0.0,
      "y": 0.0,
      "z": -0.7271
    },
    "heading": 1.49
  },
  "kinematics": {
    "velocity": 2.92,
    "acceleration": 0.2,
    "angular_velocity": 0.01
  },
  "actuation_feedback": {
    "throttle": 15.2,
    "brake": 0.0,
    "steering_angle": -0.0145,
    "gear": "D"
  },
  "energy": {
    "battery_level": 85.0
  },
  "signals": {
    "turn_indicator": "NONE",

        "y": 1970.1
      },
      {
        "x": 176332.5,
        "y": 1971.5
      }
    ]
  }
}
```

## 四、 欄位字典與業務邏輯實作指南

### 1. 識別與全域定位層 (Identification & Global Pose)
| JSON 欄位 | 型別 | 值域 / 實作邏輯說明 |
| :--- | :--- | :--- |
| `vehicle_code` | String | `PMS01` ~ `PMS11`。車輛之系統唯一識別碼。 |
| `timestamp` | Long | Unix Epoch (ms)。產生此筆資料的絕對時間戳記。 |
| `global_pose.latitude` | Double | 緯度 (WGS84)。衛星定位之絕對緯度，供前端 Web 圖台底圖定位。 |
| `global_pose.longitude`| Double | 經度 (WGS84)。衛星定位之絕對經度。 |
| `global_pose.altitude` | Double | 絕對海拔高度 (公尺)。 |

### 2. 區域相對座標與姿態 (Local Pose)
此區塊供精準地圖對位及 3D 模型旋轉使用。

> **座標系只有一套。**`local_pose.position` 使用的**場域參照座標系**（單位公尺、
> X 軸向東為正、Y 軸向北為正）與車端 ROS2 map frame **是同一套**，原點與軸向的
> 定義、各設施與停靠點的座標值一律以[車端介接說明書](車端介接說明書.md) §六 為準。
> 雙方不需要另做座標轉換或 mapping。

| JSON 欄位 | 型別 | 值域 / 實作邏輯說明 |
| :--- | :--- | :--- |
| `local_pose.position.x/y/z` | Double | 場域參照座標系中之 X/Y/Z 軸位移 (公尺)，即車端 ROS2 map frame。座標定義見[車端介接說明書](車端介接說明書.md) §六。 |
| `local_pose.orientation.w/x/y/z` | Double | 旋轉姿態四元數 (Quaternion)。**保留四元數可避免 3D 圖台發生萬向鎖 (Gimbal Lock) 現象**。 |
| `local_pose.heading` | Double | 車頭絕對朝向角 (弳度 rad)，由四元數轉換而來，供 2D 圖台快速旋轉圖標使用。 |

### 3. 車輛物理運動學 (Kinematics)
| JSON 欄位 | 型別 | 值域 / 實作邏輯說明 |
| :--- | :--- | :--- |
| `kinematics.velocity` | Double | 車輛當下實際縱向行駛速度 (**m/s**)。<br>本介面全段以 SI 單位傳輸，車端不做換算；車輛監控系統端顯示為 km/h 或 m/s 由系統度量衡參數決定。 |
| `kinematics.acceleration` | Double | 即時加速度 (m/s²)，含正負值，供車輛監控系統端監控旅客乘坐舒適度 (是否急煞)。 |
| `kinematics.angular_velocity` | Double | 車輛即時旋轉角速度 (rad/s)。 |

### 4. 底盤線控與能源燈號 (Actuation, Energy & Signals)
| JSON 欄位 | 型別 | 值域 / 實作邏輯說明 |
| :--- | :--- | :--- |
| `actuation_feedback.throttle` | Double | 即時油門踏板 / 動力輸出深度百分比 (0-100)。 |
| `actuation_feedback.brake` | Double | 即時煞車踏板 / 制動輸出深度百分比 (0-100)。 |
| `actuation_feedback.steering_angle`| Double | 即時**前輪實際轉角** (弳度 rad)，非方向盤轉角，用於精準比對控制誤差。 |
| `actuation_feedback.gear` | String | 當前變速箱/馬達運作檔位 (`P`, `R`, `N`, `D`)。 |
| `energy.battery_level` | Double | 動力電池剩餘電量 SoC 百分比 (0-100)。 |
| `signals.turn_indicator` | String | 當前方向燈閃爍狀態 (`NONE`, `LEFT`, `RIGHT`)。 |
| `signals.hazard_light` | Boolean | 雙黃警示燈是否開啟 (`true`, `false`)。進入 MRM 時通常強制為 `true`。 |

### 5. 自駕規劃預測 (Prediction)
| JSON 欄位 | 型別 | 值域 / 實作邏輯說明 |
| :--- | :--- | :--- |
| `prediction.path` | Array | 物件陣列 `[{x, y}]`。未來 3-5 秒局部預測路徑點集合 (基於 Local Frame)。供前端圖台繪製車頭前方的「預測軌跡引導線」。 |
