> **一句話**  
> **班際繼任只允許關聯圖上的短邊**（拓樸拆解後的合法可能）；「優先採用」導通組合只決定開輪偏好與同分選擇，**不得發明圖上沒有的繞回**（如 TN→NTB）。站位不夠時先延後，再**成對**改走各主線槽備用（TN→TNB 且 NT→NTB），且必須是圖上繼任的鏡像。禁止 TN→NTB。

---

## 1. 關聯圖（硬約束）

| # | 約束 | 何時生效 | 代號／行為 |
|---|------|----------|------------|
| G1 | 必須能建立有效 `RouteSuccessorPolicy`（已驗證導通＋圖有邊） | normalize 入口 | `ROUTE_SUCCESSOR_POLICY_INVALID` → 整份不排 |
| G2 | 班際下一趟＝關聯圖短邊（junction 吻合）；「優先採用」路徑僅偏好排序 | 生成／驗證 | `resolveNextInstanceId`；無邊則不排／報 `ROUTE_SUCCESSOR_MISMATCH` |
| G3 | 同列相鄰正線（中間無整備）必須是 G2 允許的下一條 | 驗證（圖模式） | `ROUTE_SUCCESSOR_MISMATCH` |
| G4 | 同列相鄰正線：前趟終點站＝後趟起點站 | 驗證（圖模式）＋站位修復 | `ROUTE_STATION_DISCONTINUITY` |
| G5 | 關聯圖**次要連線**僅在偏好路徑確實用到該邊、或約束改派需要時才走 | 策略 | `secondarySuccessors` 有資料；預設先走優先邊 |
| G6 | 站位改派備用時：成對備用必須鏡像 **G2 的繼任**（TN 的下一條是 NT ⇒ 只能 TNB＋NTB） | 站位修復 | 見 §3 |

**優先採用（Step 4）：** `preferredThroughCycleId`。同出場站多線可掛時偏好路徑越前面越好插；後續腿仍只走圖邊。

**備用路線資料：** 各主線槽的 `backupForInstanceId`（例 TNB→TN、NTB→NT）。關聯圖節點仍是主線；備用不畫在圖上，但改派必須遵守「主線繼任的槽位鏡像」。

## 2. 站位佔用（硬約束）

| # | 約束 | 說明 |
|---|------|------|
| B1 | 跨車、同停靠點，「到站～離站」區間不得重疊 | 自然靠站；不含充電／保養掛在末站 |
| B2 | 衝突時先整趟延後（10 秒格；預設上限 120s，再受同列下一正線夾緊） | 警告 `STATION_BERTH_DELAYED` |
| B3 | 延後不夠 → 成對改派備用（§1 G6） | 警告 `STATION_BERTH_BACKUP_USED` |
| B4 | 禁止留下主線再接異點備用（例 TN→NTB） | 硬閘 |
| B5 | 仍清不掉 | 錯誤 `STATION_BERTH_COLLISION`（演算法極限） |

## 3. 備用成對算法（必須遵守關聯圖繼任）

輸入：目前主線腿 `P`、同列下一正線腿 `Q`、`successorPolicy`。

1. 用關聯圖求 `expectedNext = resolveNextInstanceId(policy, P)`（只走優先／鎖定環）。
2. **僅當** `Q` 的主線實例＝`expectedNext` 時，才允許成對備用。
3. 在 `P` 的備用集合與 `Q` 的備用集合中，找一對 `(P', Q')`：
   - 折返連續：`terminal(P') = origin(Q')`（以及與前後鄰接連續）
   - 站位延後後可清開衝突
4. 同時改寫兩張班次卡：`P→P'`（例 TN→TNB）、`Q→Q'`（例 NT→NTB）。
5. 若圖上 `Q`≠`expectedNext`，或找不到連續備用對 → **不改派**，只延後或留給 `STATION_BERTH_COLLISION`。

程式：`enforceStationBerthConstraints({ successorPolicy, ... })`  
入口：`generateShiftSchedule`（整備插班之後、驗證之前）。

## 4. 其餘生成／驗證約束（摘要）

| # | 約束 | 代號（代表） |
|---|------|----------------|
| S1 | 同列任務不重疊 | `TIMELINE_OVERLAP` |
| S2 | 恢復／換線空檔 | `RECOVERY_INSUFFICIENT`、`ROUTE_SWITCH_BUFFER_INSUFFICIENT` |
| S3 | 時刻 10 秒格 | `CLOCK_ALIGN_VIOLATION` |
| S4 | 班次卡內容納逐站時刻 | `STATION_TIMING_INFEASIBLE` |
| S5 | 同向班距（時段＋跨時段取嚴＋物理地板） | `HEADWAY_*` |
| S6 | 車輛成輪／未成輪不進整備 | 掛車策略＋`ROTATION_CYCLE_INCOMPLETE` |
| S7 | 正線可偷整備／空時段／機動開頭（讓渡） | 掛車 |
| S8 | 行前／充／機動開輪第一腿用車站清除時間 | 掛車（非營運班距） |
| S9 | 折返時限 | `TURNAROUND_LIMIT_EXCEEDED`、`ROUTE_ROTATION_OVER_TURNAROUND` |
| S10 | 缺行駛／leg 無效 | `MISSING_TRAVEL_TIME`、`STATION_LEG_TRAVEL_*` |

細節見 [規則](排班引擎規則.md)、[可行性驗證清單](排班引擎可行性驗證清單.md)、[現行策略](排班引擎現行策略.md)。

## 5. 服從優先順序

1. 關聯圖有效＋鎖定全優先環（G1–G2）  
2. 成輪／同列不重疊／恢復換線  
3. 站位不撞（B1）；修復時仍服從圖繼任鏡像（G6、B3–B4）  
4. 同向班距與運能（能守則守，守不住揭缺口）  

---

## 6. 反例（禁止）

| 錯誤形態 | 為什麼錯 |
|----------|----------|
| TN 之後接 NTB | 拆了圖上 TN→NT；備用應整對 TNB→NTB |
| 只把 NT 改 NTB、TN 不動 | 同上 |
| 站位延後時無視圖、亂換任意備用 | 關聯圖是交路硬約束 |
| 用關聯圖「次要連線」當站位備援機制 | 次要＝圖標記；站位備用＝主線槽 `backupForInstanceId` |
